# List of modules

[<- Back to contents](../index.md)

## Special modules

* [Admin](https://hlmod.ru/resources/vip-admin.1641/) - gives VIP status by **admin flags** and **admin groups**
* [Admin Privileges](https://hlmod.ru/resources/vip-admin-privileges.1643/) - gives VIP players **admin flags**, **admin groups** and **admin immunity**
* [Online](https://hlmod.ru/resources/vip-online.861/) - adds the **!vips** command that shows all VIP players online
* [Test](https://hlmod.ru/resources/vip-vip-test.862/) - lets players take a trial VIP status
* [Features Manager](https://hlmod.ru/resources/vip-features-manager.756/) - controls VIP features on specific maps, rounds and during warmup
* [Language](https://hlmod.ru/resources/vip-language.239/) - lets a VIP player choose the language of menus and messages
* [Reserved Slot](https://hlmod.ru/threads/csgo-rezerv-slotov-dlja-vip.37178/) - reserved slot for VIP players

## Feature modules

## Add-on modules
* [Knife Arena Disable](https://hlmod.ru/resources/vip-knife-arena-disable.577/) - turns off the chosen VIP features while the player is in a Knife Arena
* [Last Request Disable](https://hlmod.ru/resources/vip-fm-lastrequest-off.757/) - turns off the chosen VIP features while the player takes part in a Last Request
* [Custom Rounds Off](https://hlmod.ru/resources/vip-fm-custom-rounds-off.758/) - turns off VIP features in custom rounds

## Utility modules
* [Porting](https://hlmod.ru/resources/vip-porting.355/) - moves VIP players between database types, plugin versions and other VIP plugins
* [Stats](https://hlmod.ru/resources/vip-stats.290/) - collects statistics about the core version, game and server

# VIP Core

The plugin gives players VIP status for a set period or forever.
Thanks to its modular design, the features are added by separate modules, so the functionality can always be extended.
The plugin is flexible and easy to configure, and works with both SQLite and MySQL.

Requires SourceMod 1.10 or newer.
